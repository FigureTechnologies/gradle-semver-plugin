# Semver Gradle Plugin

Semantic versions from your git history — across strategies, branches, and the messy states real builds hit.

Apply the plugin, build, and optionally shape the next version with `-Psemver.stage` / `-Psemver.modifier`. For install steps and a compact config example, see the [GitHub README](https://github.com/figuretechnologies/gradle-semver-plugin#readme).
